# ProCode Dev

Landing page oficial de **ProCode Dev**, desarrollada con **Astro** y **TailwindCSS**.

ProCode Dev es una marca enfocada en desarrollo web estratégico, landing pages, integraciones, automatización y sistemas digitales para negocios que buscan mejorar su presencia digital, captar mejores prospectos y operar de forma más ordenada.

---

## Descripción del proyecto

Este proyecto corresponde a la landing page principal de ProCode Dev.

La página está diseñada con una estética tecnológica, premium y moderna, alineada visualmente con el ecosistema de ProCode Systems, pero enfocada específicamente en servicios de desarrollo web, captación digital e integraciones.

El objetivo de la landing es comunicar de forma clara los servicios de ProCode Dev y dirigir a los visitantes hacia una acción concreta: agendar un diagnóstico, solicitar una propuesta o contactar por WhatsApp.

Instalación y uso
1. Clonar el repositorio
git clone https://github.com/tu-usuario/procodedev.git

2. Entrar al proyecto
cd procodedev

3. Instalar dependencias
npm install

4. Ejecutar servidor de desarrollo
npm run dev

El proyecto estará disponible normalmente en:
http://localhost:4321

5. Generar build de producción
npm run build

El resultado se generará en la carpeta:
dist/

6. Previsualizar build de producción
npm run preview

Configuración de TailwindCSS

El proyecto utiliza TailwindCSS v4 con integración mediante Vite.

Archivo principal de estilos:
src/styles/global.css
